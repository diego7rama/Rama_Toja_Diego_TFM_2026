# Diseño, desarrollo y automatización de una planta industrial virtual

Repositorio asociado al Trabajo Fin de Máster "Diseño, desarrollo y automatización de una planta industrial virtual".

## Autor

Diego Rama Toja

## Descripción

Este repositorio contiene los archivos utilizados para el desarrollo, automatización y supervisión de una planta industrial virtual orientada a procesos de clasificación y ensamblaje automatizado.

## Contenido

- Proyecto de simulación 3D de la planta.
- Proyecto de programación del PLC.
- Proyecto de visualización y supervisión SCADA.
- Listado de variables y señales.
- Capturas y documentación auxiliar.

## Software empleado

- Factory I/O
- Unity Pro-XLS
- Vijeo Citect
